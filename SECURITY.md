# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub's security advisories: on the
repository page, go to **Security > Advisories > Report a vulnerability**
(see GitHub's documentation on "Privately reporting a security
vulnerability"). Please include the affected version, the Froxlor version,
steps to reproduce and the impact you see.

You will get an answer as soon as possible. Once a fix is available, the
advisory is published together with a new release.

## Scope

The part of this theme that is reachable without logging in is
`theme_agency.php` in Froxlor's root directory. Its security properties are
described in the README under "Security model". Vulnerabilities in Froxlor
itself should be reported to the Froxlor project.

## Supported versions

Only the latest release receives security fixes.
